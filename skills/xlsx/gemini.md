# XLSX Spreadsheet Skill: Creation, Editing, and Analysis

## 1. Quick Decision Matrix

Determine the correct tool and strategy before executing:

| Task / Goal | Method / Library | Critical Guardrails |
|---|---|---|
| **Create / Format / Formulas** | `openpyxl` | Write formulas as strings. **Never** hardcode computed totals. |
| **Bulk Data Import / Export** | `pandas` (`read_excel`, `to_excel`) | Fast processing, but drops custom openpyxl styling and charts. |
| **Quick Content Inspection** | `markitdown file.xlsx` | Reads text per sheet (`## SheetName`). No cell coordinates. |
| **Read Formulas AND Values** | Two-pass `openpyxl.load_workbook` | Pass 1: `data_only=False` (formulas). Pass 2: `data_only=True` (values). |

## 2. Standard Execution Workflows

### Workflow A: Creating or Editing Spreadsheets (`openpyxl`)


```

[Define Layout/Formulas] ──> [Write Python Script] ──> [Execute Script] ──> [Recalculate (recalc.py)] ──> [Validate Errors]

```

1. **Write openpyxl Script**: Apply typography, cell formatting, and formulas.
2. **Execute Python Script**: Generate or modify the target `.xlsx` file.
3. **Mandatory Recalculation Step**:
   ```bash
   python scripts/recalc.py output.xlsx

```

*Note: openpyxl does NOT evaluate or cache formula results. `recalc.py` uses LibreOffice to compute all cells and generate cached values.*
4. **Evaluate Recalc Output**:

* Check the JSON summary for `status: "success"` and `total_errors: 0`.
* If `errors_found` is returned, inspect the listed cell locations, fix the formula logic, and rerun.

### Workflow B: Preserving Existing Models & External Links

```
[Check External Links] ──> [Backup Original Values] ──> [Apply Edits] ──> [Recalculate with Caution]

```

1. **External References Check**: If formulas reference external workbooks (e.g., `='[1]Returns Analysis'!$B$2`), openpyxl will purge cached values on save, and `recalc.py` will replace them with `#NAME?`.
2. **Preservation**: Copy cached values from the original file (`data_only=True`) before saving over cells containing unresolved external links.

## 3. Essential Technical Standards & Footguns

### Formula Rules (LibreOffice Compatibility)

* [ ] **Excel-2007 Classic Functions (Safe)**: Always prefer `SUMIFS`, `INDEX`, `MATCH`, `IFERROR`, `SUMPRODUCT`.
* [ ] **Prefixed Functions (Use `_xlfn.`)**: The following 6 post-2007 functions **must** be prefixed with `_xlfn.` or they evaluate to `#NAME?`:
* `_xlfn.TEXTJOIN`
* `_xlfn.CONCAT`
* `_xlfn.IFS`
* `_xlfn.SWITCH`
* `_xlfn.MAXIFS`
* `_xlfn.MINIFS`


* [ ] **STRICTLY BANNED Functions**: **Never** use `XLOOKUP`, `XMATCH`, `SORT`, `FILTER`, `UNIQUE`, or `SEQUENCE`. Headless LibreOffice cannot process array spilling metadata generated by openpyxl, causing silent truncation or errors. Use `INDEX`/`MATCH` or perform sorting/filtering in Python before writing.
* [ ] **Cross-Sheet Syntax**: Sheet names containing spaces MUST be wrapped in single quotes (e.g., `='Assumptions Inputs'!$B$5`).

### openpyxl API Traps

* [ ] **Destructive `data_only=True**`: Saving a workbook loaded with `data_only=True` permanently destroys all formulas and replaces them with static values.
* [ ] **Merged Cells**: Write values and styles ONLY to the top-left cell of a merged range. Other cells in the range are read-only `MergedCell` instances.
* [ ] **Macro Preservation**: When loading `.xlsm` files, pass `keep_vba=True` to `load_workbook` to avoid stripping VBA projects.

## 4. Financial Modeling & Formatting Standards

Apply these formatting rules unless explicitly instructed otherwise:

### Visual Hierarchy & Font

* **Font**: Standardize on **Arial** or **Calibri** across the entire workbook.
* **Color Conventions**:
* **Blue Text (`0000FF`)**: Hardcoded inputs and scenario levers.
* **Black Text (`000000`)**: Formulas and calculated values.
* **Green Text (`008000`)**: Cross-sheet or external links.
* **Yellow Fill (`FFFF00`)**: Input cells requiring user entry.



### Number Formatting Rules

* **Currency**: Use `$#,##0` or `$#,##0.00`. Set zero values to render as dashes (`$#,##0;($#,##0);-`).
* **Percentages**: Store as decimals (e.g., `0.15` for 15%) and apply format `0.0%`. Storing `15` will incorrectly render as `1500.0%`.
* **Multiples & Years**: Format valuation multiples as `0.0x`. Format years as explicit text (`"2026"`), never as raw numbers (`2,026`).

## 5. Helper Script Reference

All scripts reside in `scripts/` relative to the skill directory:

* `scripts/recalc.py input.xlsx [timeout]` — Headless LibreOffice wrapper that recalculates all formulas, writes cached values, and returns an error diagnostic JSON summary.
* `scripts/office/soffice.py` — Sandboxed LibreOffice binary wrapper.

## 6. Verification & Quality Assurance Checklist

Every output workbook must pass these 4 verification checks:

1. **Zero Formula Errors**: Run `python scripts/recalc.py output.xlsx`. Verify `total_errors` is `0`.
2. **No Hardcoded Output Totals**: Ensure summary metrics and totals use dynamic formulas (e.g., `=SUM(B2:B9)`) instead of static values evaluated in Python.
3. **Spec Alignment**: Column headers, tab names, and formula structures must match the user's specification verbatim.
4. **Assumption Documentation**: Document all hardcoded drivers or assumptions in dedicated input cells or adjacent cell comments with source citations.
